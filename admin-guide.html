1국토부 사이트 접속

국토교통부에서는 모든 부동산 거래 데이터를 완전 무료로 공개합니다. 회원가입 없이 누구나 받을 수 있어요.

🔗 접속 주소

https://rt.molit.go.kr/pt/xls/xls.do

위 링크는 국토부 실거래가 공개시스템 → "실거래가 자료 제공" 페이지로 바로 이동해요.

🚀 국토부 사이트 바로 열기
💡 알아두세요
국토부 사이트는 Internet Explorer에서 잘 동작합니다. Chrome에서 안 되면 Edge를 쓰셔도 좋아요.

2광주·전남 데이터 다운로드

  1. 거래 유형 선택: 화면 상단 또는 좌측 메뉴에서 다음 중 원하는 것을 클릭
    • 🏢 아파트(매매) - 가장 자주 사용
    • 🏘️ 아파트(전월세)
    • 🏠 연립/다세대(매매) = 빌라
    • 🏬 오피스텔(매매)
    • 🏪 상가/사무실(매매)
  2. 지역 선택: 시도 항목에서 광주광역시 또는 전라남도 선택
    시군구는 전체로 두면 한 번에 받을 수 있어요.
  3. 계약년월 선택: 최근 1~3개월 선택
    예: 2026년 02월 ~ 2026년 04월
  4. 다운로드 버튼 클릭: 화면에 표시되는 파란색 EXCEL 다운로드 버튼 클릭
  5. 파일 저장: 실거래가_공개시스템_xxxxx.xlsx 파일이 다운로드됨
📌 처음 다운로드 시
국토부 사이트는 보안 프로그램 설치를 요구할 수 있어요. 안내에 따라 설치하시면 됩니다 (1회만).

3엑셀에서 TOP 10 정렬

받은 엑셀 파일을 열고, 거래금액이 높은 순서로 정렬해서 상위 10개를 뽑아요.

  1. 엑셀 파일 더블클릭으로 열기 (Microsoft Excel 또는 무료 LibreOffice)
  2. 제목 행이 1~5행에 있으면 해당 행 삭제 (실제 데이터부터 시작)
  3. 모든 데이터 선택: Ctrl + A
  4. 데이터 메뉴 → 정렬 클릭
  5. 정렬 기준: 거래금액(만원) 열 선택
    정렬 방향: 내림차순(큰 값 → 작은 값)
  6. 상위 10개 행만 선택해서 복사 (Ctrl + C)

4변환기에서 JSON으로 변환

  1. 변환기 페이지 열기: 주소창에 https://gwangsabu.kr/admin-converter.html 입력
  2. 지역 선택: 광주광역시 또는 전라남도 클릭
  3. 엑셀에서 복사한 데이터를 큰 입력 칸에 붙여넣기 (Ctrl + V)
  4. "🔄 JSON으로 변환" 파란 버튼 클릭
  5. 화면 하단에 미리보기 표 + 변환된 JSON 코드가 나타남
  6. "📋 JSON 코드 복사" 또는 "💾 파일 다운로드" 버튼 클릭
🛠️ 변환기 페이지 열기
📌 처음 사용하시면
변환기 페이지에 "📝 예시 데이터 불러오기" 버튼이 있어요. 한 번 눌러서 어떻게 동작하는지 확인해보세요!

5GitHub에 data.json 업로드

  1. GitHub 접속: https://github.com/광사부2026/광사부
  2. data.json 파일 클릭
  3. 우측 상단 연필 아이콘 ✏️ 클릭 (Edit this file)
  4. 해당 지역 부분 (TOP10_광주 또는 TOP10_전남) 찾기
  5. 변환기에서 복사한 JSON으로 교체 (붙여넣기)
  6. 화면 맨 아래로 스크롤
  7. "Commit changes" 초록 버튼 클릭
⚠️ 주의
JSON 형식이 깨지면 사이트가 안 나올 수 있어요. 콤마(,), 따옴표("), 중괄호({}) 위치를 정확히 유지하세요!

6Cloudflare 캐시 정화 + 확인

  1. Cloudflare 접속: https://dash.cloudflare.com
  2. gwangsabu.kr 사이트 클릭
  3. 왼쪽 메뉴 → 캐싱 → 구성
  4. "모든 것을 제거하기" 파란 버튼 클릭
  5. 팝업에서 다시 한번 "제거하기" 클릭
  6. 3~5분 대기 ⏰
  7. 시크릿 창 (Ctrl+Shift+N)으로 gwangsabu.kr 접속해서 변경 확인

7자주 묻는 질문 (FAQ)

Q1. 매주 받아야 하나요?

국토부 데이터는 거래 후 30~60일 시차가 있어요. 월 1~2회면 충분합니다. 매월 1일과 15일을 추천드려요.

Q2. 빌라/상가도 같은 방법인가요?

네! 국토부 사이트에서 거래 유형만 다르게 선택하시면 같은 방식으로 받을 수 있어요. 단, 광사부 사이트는 현재 아파트 매매만 표시되니, 빌라/상가는 향후 페이지 추가 시 사용하세요.

Q3. 상승률(▲8.2%)은 어떻게 계산되나요?

현재 변환기는 임의로 상승률을 부여합니다. 정확한 상승률이 필요하면 직접 JSON에서 수정하세요. 향후 직전 거래와 자동 비교 기능을 추가할 예정이에요.

Q4. 단지명이 잘못 나와요

국토부 데이터는 단지명이 일관되지 않을 수 있어요. JSON에서 직접 수정하시면 됩니다. 또는 변환 후 미리보기에서 확인하고, 이상한 데이터는 변환기에 붙여넣기 전에 엑셀에서 미리 정리하세요.

Q6. 데이터가 사이트에 안 나타나요

다음을 차례로 확인하세요:

  1. data.json 파일이 GitHub에 정상 업로드 되었는지
  2. JSON 문법이 깨지지 않았는지 (jsonlint.com 에서 검증)
  3. Cloudflare 캐시를 정화했는지
  4. 시크릿 창에서 확인했는지
  5. 브라우저 개발자 도구(F12) → Console에서 에러 확인
