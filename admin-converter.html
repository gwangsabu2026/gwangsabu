🛠️ 엑셀 → JSON 변환기

국토부 엑셀 데이터를 광사부 사이트 데이터로 변환하는 관리자 도구

1
국토부 엑셀 다운로드 rt.molit.go.kr
2
엑셀에서 복사 Ctrl+A → Ctrl+C
3
아래 칸에 붙여넣기 Ctrl+V
4
변환 → 다운로드 data.json 받기

📥 1단계: 엑셀 데이터 붙여넣기

국토부에서 다운받은 엑셀에서 데이터를 복사(Ctrl+A → Ctrl+C)한 후 아래에 붙여넣기(Ctrl+V) 하세요.

📌 엑셀 형식 (탭으로 구분된 데이터)
열 순서: 시군구 / 본번 / 부번 / 단지명 / 전용면적 / 계약년월 / 계약일 / 거래금액 / 층 / 건축년도

✅ 2단계: 변환 결과 미리보기

📦 3단계: data.json에 붙여넣을 코드

아래 JSON을 복사해서 GitHub의 data.json 파일에 붙여넣으세요.

📖 사용 가이드

1. 국토부 엑셀 받는 방법

  1. 접속: rt.molit.go.kr/pt/xls/xls.do
  2. 실거래가 자료 제공 → 아파트 매매 선택
  3. 지역: 광주광역시 또는 전라남도 선택
  4. 계약년월: 최근 1개월
  5. 다운로드 버튼 클릭 → 엑셀 파일 받기

2. 엑셀에서 데이터 복사

  1. 엑셀 파일 열기
  2. 거래금액 기준 높은 순으로 정렬 (TOP 10)
  3. 상위 10개 행 선택
  4. Ctrl+C로 복사
  5. 이 페이지로 와서 Ctrl+V로 붙여넣기

3. 추천 업데이트 주기

  • 매월 1일·15일 (월 2회): 가장 추천 ⭐
  • 매월 1일 (월 1회): 최소
  • 주 1회: 더 신선하게
💡 팁
국토부 데이터는 신고 후 30~60일 시차가 있어요. 4월 데이터는 5~6월에 가장 정확하게 나오니 너무 자주 받을 필요는 없어요!
